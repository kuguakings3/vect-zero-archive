# Vect Zero · 世界运行档案馆

这是 Vect Zero 的独立静态设计档案网站，与游戏本体仓库分离。网站使用原生 HTML、CSS、JavaScript，无需安装依赖、数据库、API 密钥或构建步骤。

## 页面内容

- **总览**：设计摘要、示意地图与核心原则
- **世界地图**：可点击的虚构地点与空间层级
- **任务时间线**：可选事件，查看世界真实状态、现场认知和玩家情报
- **任务状态**：命令传递、现场执行、任务成果、通信状态与指挥权限
- **物资账本**：弹药发现、装车、暂存、入库与弹药箱 5% 取用优惠示例
- **异常沙盘**：据点失守、司机失能、弹药争用、命令延迟
- **设计原则**：世界状态、资源守恒、指挥权限和边界场景等不变量

## 本地预览

直接打开 `index.html` 即可。也可以在本目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 免费发布到 GitHub Pages

1. 打开本仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中将 **Source** 设为 **GitHub Actions**。
3. 之后每次向 `main` 分支推送变更，`.github/workflows/pages.yml` 会自动部署网站。
4. 在 **Actions** 中查看工作流是否成功；完成后可在 **Settings → Pages** 找到访问地址。

预计地址格式为 `https://kuguakings3.github.io/vect-zero-archive/`；只有在 GitHub Pages 部署成功后，该地址才会真正可访问。

## 设计状态与数据边界

本网站的地图、事件、库存和异常场景均为虚构的设计演示数据，不连接 Vect Zero 游戏，也不代表游戏内功能已经实现。规则仍是设计草案，后续修改应保留记录，不要仅因为出现在网站上就标记为已完成。

## 安全与维护

- 本仓库只存放设计网站，不包含游戏源代码、密钥或服务器配置。
- 网站为纯静态前端，不收集或提交用户数据。
- 页面内的交互仅用于浏览和筛选设计档案，不会修改游戏状态。
